# Isaac Newton — A Tribute

A single-page HTML/CSS/JS tribute to Sir Isaac Newton, built for the "Level 2 — Tribute Page" task.

## Files
```
index.html      → all page content and structure
css/style.css   → every style (colours, type, layout, animation)
js/script.js    → ribbon-nav highlighting + the apple click interaction
```

## What makes this one different
- **A palette with no blue at all** — everything is built from candlelight black, brass, oxblood/burgundy and aged parchment, on purpose.
- **A CSS-only Newton's Cradle** swinging in the hero — a nod to his First Law, built with plain keyframe animation, no libraries.
- **A clickable apple** in the "plague years" section that actually falls when you click it.
- **A ribbon/bookmark side-nav** instead of a normal navbar, styled like tabs sticking out of a book.
- **Torn-paper page dividers**, drop capitals on each section's opening line, a wax-seal monogram beside the quote, and a "letter" tucked into the page for the personal reflection — all small nods to a 17th-century manuscript rather than a generic template.
- The prism graphic is intentionally rendered in the page's own warm palette rather than a true rainbow, and says so in its caption — a way of turning the "no blue" rule into a feature instead of a limitation.

## Personalizing it
- The closing line of the "Why I admire him" letter (`<p class="signoff">`) is a good place to add your own name.
- The footer credit line can be edited the same way.

## A note on the portrait
The hero image links directly to a public-domain 1702 portrait of Newton (after Sir Godfrey Kneller) hosted on Wikimedia Commons, so it needs an internet connection to load. If it can't load, the page automatically swaps in a small illustrated silhouette instead — the page never shows a broken image icon.
