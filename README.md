
# Full-Stack React Multi-Page Ecosystem

This repository contains two enterprise-grade React applications generated via the Turbo Autonomous Pipeline.

## Level 1 Task 1 (Portfolio)
A fully responsive, multi-page portfolio for an AI & Cyber Security Developer.
- **Theme Engine**: Light/Dark mode with dynamic CSS variables (Emerald & Obsidian).
- **Data Driven**: Content powered by `cardsConfig.js` decoupling logic from presentation.

## Level 2 Task 1 (Historic Pioneer Tribute)
An editorial, cinematic tribute to Sir Isaac Newton.
- **Interoperability**: Reuses the exact same polymorphic `<Card />` API.
- **Immersive Design**: Uses 'Cinzel' typography and glass-morphism effects.

## How to Run Locally
1. Navigate into either project directory: `cd "level 1 task 1"` or `cd "level 2 task 1"`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`

## Architecture Highlights
- Uses `react-router-dom` (HashRouter) to prevent static hosting 404s.
- Strictly decoupled `Card` elements for infinite scalability.
