# Historic Pioneer Tribute: Sir Isaac Newton (Level 2 Task 1)

This project is an immersive, editorial-style tribute website dedicated to Sir Isaac Newton, highlighting his biography, technical breakthroughs, and core virtues.

## Features
- **Interoperable UI Architecture**: Shares the exact same polymorphic Card.jsx component API as the Level 1 Portfolio, demonstrating robust component reusability across entirely different visual contexts.
- **Editorial Design System**: Features a classic, museum-grade aesthetic using "Cinzel" and "Montserrat" typography, complemented by a bespoke Gold and Amber dark theme engine.
- **Data-Driven Content**: All biographical eras, quotes, and timeline milestones are cleanly structured within src/config/cardsConfig.js.
- **Interactive Elements**: Includes a curated quote catalog with one-click clipboard copying and fluid CSS micro-animations.

## Pages Include:
- **Home**: Cinematic hero banner with a historic 1689 portrait and overview of his foundational pillars.
- **Biography**: In-depth historical narrative of his life eras and a dedication to modern engineers.
- **Breakthroughs**: Technical breakdown of his architectural inventions (Calculus, Reflecting Telescope, etc.).
- **Virtues**: Core mindset principles to emulate.
- **Timeline**: Chronological milestone roadmap.
- **Quotes**: Interactive archive of his most famous words.
